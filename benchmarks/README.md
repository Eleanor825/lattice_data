# Target Compiler Benchmarks

This directory stores small, fixture-backed benchmark artifacts for the target-compiler release flow.

Phase-1 and Phase-2 coverage:

- RAG fixture checks
- SFT fixture checks
- Eval fixture checks
- provenance and reproducibility checks
- entity linking and conflict reporting checks
- target-aware score reporting checks
- source governance checks
- transform extension checks

The goal is not large-scale leaderboard benchmarking. The goal is to provide stable, inspectable release evidence.
